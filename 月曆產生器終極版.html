Chrome OS Flex 擴充元件安裝說明

若要在 Chrome OS Flex / Chrome 瀏覽器中將此工具包裝為原生擴充元件，請在資料夾中建立以下檔案：

1. manifest.json 
{
  "manifest_version": 3,
  "name": "A4 台灣客製化月曆生成器",
  "version": "1.0",
  "description": "自動產生 A4 橫式/直式單張台灣節日月曆",
  "action": {
    "default_popup": "index.html",
    "default_icon": "icon.png"
  },
  "permissions": []
}
2. 安裝步驟
  1. 將本檔儲存為 index.html 與上述 manifest.json 放於同資料夾。
  2. 開啟 Chrome 瀏覽器，網址列輸入 chrome://extensions。
  3. 開啟右上角「開發者模式」。
  4. 點擊「載入未封裝項目」，選擇該資料夾即可安裝完成！
